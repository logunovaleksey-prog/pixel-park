# Пиксель-Парк

Три браузерные мини-игры в одной аркаде. Открываются по ссылке на телефоне и компьютере, без скачивания.

- **Неоновая трасса** — пиксельная гонка от первого лица в стиле 80-х (`#race`)
- **Квиз-Пати** — викторина на время с бонусом за скорость (`#quiz`)
- **Бургер-аврал** — кухня: собери бургер по чеку, пока гость не ушёл (`#kitchen`)

Играть: https://logunovaleksey-prog.github.io/pixel-park/
